# Declaración de uso de IA
Se utilizó ChatGPT como apoyo para comprender requisitos, proponer una estructura sencilla, generar ejemplos de Java/XML, explicar Firebase, GPS, Maps y sensores, y revisar errores.

Consultas de ejemplo:
- Ayúdame paso a paso a realizar GeoRegistro en Android Studio con Java.
- Explícame cómo conectar Firebase Firestore.
- ¿Cómo solicito permiso de ubicación?
- ¿Cómo muestro una incidencia en Google Maps?
- ¿Cómo uso el acelerómetro?

El estudiante debe revisar, ejecutar y modificar el código y explicar personalmente su funcionamiento durante la interrogación.
